# Myla 的一天

一个记录「一天的时间都去哪了」的小 app：中间一个 24 小时圆盘，点一下就切换当前在做的事，一天慢慢被颜色填满。除了圆盘，还有今天的清单、长期目标树、倒数日，以及一个会陪着你的像素小家伙 Clawd。

跑在 [Scriptable](https://apps.apple.com/us/app/scriptable/id1405459188) 里——不用 Xcode、不用 iCloud、不用开发者账号、不会 7 天过期，手机上装一个免费 app 就行。数据全在本机，不上传任何服务器。

## 为 ADHD 友好的设计

这个 app 从头到尾做了很多适合 ADHD 的取舍，核心是两条：**不施压、不替你造假数据**。

- **记录零摩擦**：点一下就切状态，长按之外没有任何「开始/停止计时器」要伺候。忘了记也能点扇形补录。
- **做完的不消失**：清单勾掉的事沉到底下、留着打勾时间，一天结束能看见自己干了什么——比清空列表更有成就感，也不制造「还剩好多」的焦虑。
- **不自动开始任务**：清单是「打算做的」，圆盘记的是「真在做的」，两件事互不替对方做决定。勾完一条不会自动切状态，切状态也不会假装你完成了什么。
- **不自动猜、不替你决定**：睡觉那种没人能替你点的长段，app 只会**提醒**你「这段有点长，中间换过吗」，绝不自作主张切成睡觉——猜错了圆盘就不可信。
- **手动优先**：地点自动切换只在你没有刚手动设过状态时生效，你亲手记的东西自动化动不了。
- **看得见的长期进度**：目标树用「完成了多少真实待办」长大，不搞「手动浇水」那种凭感觉点的假多巴胺——进度是真的才有意义。
- **提醒不打扰**：定时问一句直接做成通知，锁屏上点一下就改，不用打开 app 打断当下。

## 三个页面

**今天**（打开就是）：24 小时圆盘 → 点一下切当前状态 → 今天的清单 → 目标树 → 倒数日 → 别的。

圆盘上午夜在正上方，顺时针一圈就是一天。当前状态在圆盘中间显示，还能把中间的 Clawd 换成自己的一张图。

**统计**（「别的 → 看圆盘 / 统计」进）：两排切换器，上面选时间粒度 `周 / 月 / 3个月`，下面选图形 `柱状 / 圆盘`。柱状是每天一根的堆叠柱，3 个月自动收成一周一根；圆盘是这段时间各状态的占比。下面的列表点进去是单项详情——总计、有记录的天平均、出现过几天、最长的一次是哪天几点。选过的粒度和图形会记住。

（刻意没做「平均每天几小时」这个总览数字：这个 app 里永远有一个状态在跑，每天总和必然接近 24 小时，平均下来永远是 24，没意义。单项的平均才有用。）

## 目标树（长期规划）

「目标」板块立几个长期目标——实习、科研、健身……每个是一棵会长大的像素树。给待办绑上目标，完成一条就是给那棵树浇一次水：

> 种子 → 嫩苗（第一条）→ 小树（5 条）→ 大树（12 条）→ 开花结果（25 条）

树靠真实完成的待办长大，不是凭感觉点浇水——看得见的长期进度是 ADHD 研究里少数被反复验证有效、又不属于「假多巴胺」的东西，前提是它映射真实的事。加待办时可以顺手绑一个目标，不绑也行。删目标不动已有的待办，也不回退已经长出来的进度。

## 今天要做的（清单）

打勾就完事，不弹窗不追问。做完的沉到底下、记下打勾时间，不消失。昨天没做完的会问一句「搬过来？」，不自动搬。

## 倒数日

「别的 → 倒数日」记重要的日子，显示在**大号小组件右边**。生日纪念日打开「每年重复」，过完自动滚到明年；已经过去的日子排在最后、数字变淡。按「天」算不按 24 小时算——今晚 23:00 到明早 8:00 是「明天」，不是「还有 9 小时」。

## 微信消息进待办

iOS 上没法让 app 直接读微信聊天（系统沙盒不允许，微信也没开放个人消息接口）。能做到的最接近版本是：**在微信里复制一条消息 → 敲两下手机背面 → 自动进待办**。

脚本收到剪贴板内容后会自己拆条：按行和句号分开、去掉序号和「记得/麻烦/帮我」这类开场、丢掉「好的收到哈哈哈」纯客套、按内容去重，直接写盘再弹通知确认，全程不打开 app。宁可多收一条（删掉只要两下），也不漏掉正事。

配置一次：
1. 快捷指令 → ＋ → 动作「获取剪贴板」
2. 动作「文本」，内容写 `todo:` 再接上剪贴板变量
3. 动作 Scriptable「Run Script」，脚本选 `Myla`，Parameter 选上一步的文本
4. 命名「进待办」→ 设置 → 辅助功能 → 触控 → 轻点背面 → 轻点两下 → 选「进待办」

之后：微信长按消息 → 复制 → 敲两下背面 → 通知「记到今天要做的了 ✓」。

> 想更进一步的自动化（转发给一个挂在 Claude 上的小号，自动理解、抽取、进队列，打开 app 时同步）也做得到，代码在另一个私有目录，需要一台常开的电脑或小服务器。

## Clawd

圆盘中间那个橙色小家伙会跟着当前状态换动作：睡觉闭眼冒 Zzz、科研抱电脑、学习抱书、吃饭端碗、通勤背包、运动举哑铃、休息端杯子、刷手机低头、上课举手。圆盘和小组件共用同一份绘制代码，两边同步。不喜欢的话可以在「别的 → 中间的形象」换成自己相册里的一张图。

## 小组件

长按主屏 → ＋ → Scriptable → 选尺寸 → 编辑 → Script 选 `MylaWidget`。三个尺寸：小号只有圆盘，中号圆盘 + 最近一个倒数日 + 时长，大号左边圆盘和时长、右边五个倒数日。跟主 app 读同一个数据文件，自动同步。

## 地点自动切换（在「快捷指令」里配）

Scriptable 自己不能在后台监听地理围栏，但系统的快捷指令可以：

1. 快捷指令 → 底部**自动化** → ＋ → **到达**
2. 选地点（比如实验室），选「立即运行」，关掉「运行前询问」
3. 动作里搜 **Run Script**，Script 选 `Myla`
4. 展开动作，**Parameter** 填状态名，比如 `科研`（填 id `research` 也认）

离开时切成别的就再建一条「离开」的自动化。每个地点配一次，之后就不用管了。触发时脚本直接切状态并退出，不弹界面，不打断你。

### 手动优先

地理围栏会反复触发（在围栏边上走两步就是一次进出）。为了不让自动化把你手动记的东西冲掉：每一段都记着是谁切的，**你亲手设的状态在保护期内自动化不许改**（默认 30 分钟，「别的 → 自动切换」里可调，也能完全关掉）。被跳过时首页会明说「自动化想切成休息，你 8 分钟前刚手动设成学习，没动它」。通知按钮不算自动——那是你自己按的，直接生效。

记岔了也能改：统计 → 点那个状态 → 点某一段 → 整段改成别的状态。自动化切出来的段在列表里标着「自动」。

## 定时问一句

「别的」里能设间隔（默认 90 分钟，可关）。超过这个时长没换状态，就推一条通知：

> **还在学习吗？**
> 已经 1 小时 50 分。点一下确认或者改掉，圆盘就不会记错。
> 　[ 改成科研 ]　[ 改成休息 ]

按钮直接在通知上，点了就切，不用打开 app。旁边两个是当天用得最多的另外两个状态。每次切换都会把下次问话往后推。

## 睡觉那一段

睡着之后没人能替你点，所以早上起来那一大段一定不准。首页会主动提示：

> ✂︎ 这一段已经 9 小时 12 分，中间换过吗？

点开输入几点睡的、选后半段是「睡觉」，一刀切成两段。app 不会到点自动切睡觉——那是替你猜，猜错圆盘就不可信，边界由你说了算。

## 装

**1. 手机装 [Scriptable](https://apps.apple.com/us/app/scriptable/id1405459188)**（App Store 免费）。

**2. 新建一个脚本，把 `MylaGet.js` 的内容粘进去，跑一次。** 它会自动拉最新版的全部脚本到本地，跑完弹窗告诉你装到了哪一版、数据文件在不在。

**3. 放个主屏幕图标**（不用每次先开 Scriptable）：
1. 快捷指令 → ＋ → 搜「打开 URL」→ 填 `scriptable:///run?scriptName=Myla`
2. 命名「Myla 的一天」→ 保存 → 长按 → 分享 → 添加到主屏幕 → 图标换成 `icon.png`

**4. 加小组件**：见上面「小组件」。

装完就不用再手动更新了——app 每次打开会自己对一下最新版，有新的静默下好，下次打开生效。`MylaGet` 只在第一次装、或哪天出问题时才用得到。

## 数据安全

脚本和数据是分开的两组文件，更新只覆盖 `.js`，`myladay*.json` 一律不碰。写入走「先写临时文件 → 读回核对 → 现有的存成备份 → 才替换正式文件」，中途崩溃时正式文件仍是上一份完整的。读取时如果 JSON 解析失败不会静默清空：坏文件改名留档，用备份恢复，界面上给提示。数据结构带版本号，升级会自动补齐老结构缺的字段。「别的 → 导出一份备份」可以存一份到「文件」App。

## 文件结构

```
MylaCore.js    数据读写 + 圆盘/占比环/倒数日/目标树/Clawd 绘制（app 和小组件共用）
MylaView.js    网页视图层（圆盘、统计的 HTML/CSS）
Myla.js        主脚本：主界面、存盘、自动更新、快捷指令入口
MylaWidget.js  主屏小组件
MylaWhy.js     记录不对劲时跑它，把真实数据摊开看
MylaGet.js     引导脚本，第一次装 / 出问题时用
```

会改数据的操作（切状态、待办、目标、倒数日、管理状态）都走脚本这边的原生列表，点一下当场落盘，最稳。圆盘、统计这些只用来「看」的放在网页里，界面更自由。

## 给改代码的人

改完跑 `./check.sh`，它盯着几处容易踩的坑（顶层 await、被模板字符串包住的页面 JS 语法、模板里被吞掉的反斜杠转义、定义了没人调的函数），并用 `smoke.mjs` 把整个 `Myla.js` 用打桩的 Scriptable API 端到端跑一遍。绘制类改动可以在浏览器里按 iPhone 尺寸渲染核对，验证时用真实点击而不是直接调函数。
